### HybridCache composition gap retained

HybridCache 10.11.0 net10 depends on **10.0.13** Caching.Abstractions/Memory/Logging.Abstractions/Options; its own unchanged public contract does not supply the new context types. The RC2 base abstraction provides a virtual fallback: suppress inner writes, run a context-aware factory, then SetAsync with final options only when the factory ran. It explicitly documents race tradeoffs and writes with CancellationToken.None after completion. This bounds the API contract but does not prove that the separately compiled 10.11.0 implementation honors new LocalSize, distributed behavior or all concurrent-follower cases. PIN-747 must resolve the actual selected dependency closure and execute the claimed size/expiry/cache-hit/stampede behavior. An unverified LocalSize implementation remains a delivery gap; do not relabel source or reference metadata as runtime proof.

### Public tooling reconciliation

The source manifest mechanically compares four paired generator descriptor files and retains complete changed source lines, not just a summary-page claim:

- Binder **5 → 5** SYSLIB1100–1104 IDs; descriptor source unchanged. ConfigurationIgnore, interception and automatic bug fixes do not introduce a new descriptor recipe. PIN-745 must test its actual generated consumer.
- Options descriptor set **17 → 18** (base descriptor file compared separately): new **SYSLIB1219** rejects a handwritten ValidateAsync implementation. Existing **SYSLIB1205** also applies to explicit Validate after the RC1 detection change, already audited by PIN-685. **Grouped → PIN-746:** choose generated or handwritten ownership for each capability; no blanket suppression.
- Logging **26 → 28** IDs: SYSLIB1011 changes from rejecting generic methods to rejecting `allows ref struct`; new SYSLIB1028/1029 reject unsupported params/ref-struct parameter forms. **Grouped → PIN-749**, with actual failing/fixed builds and recorded logging output, not a new generic-logging ticket.
- Validation package's new analyzer implementations advertise **ASP0033–ASP0038**: inaccessible marked type, inaccessible endpoint type, inaccessible property/type for marked or endpoint models, a generated-code marker, and a marker without AddValidation. Old/new generator entry points and new shipped/unshipped rule tables are pinned; the new table calls these “Unshipped”, which is source release tracking, not proof they are absent from the downloaded binary. Shared-host/marked-type checks belong with E4/PIN-748; endpoint checks remain PIN-709 and existing form/endpoint owners. No analyzer suppression stands in for actual coverage.

The hashed binaries establish which tooling shipped, while descriptor review bounds the intended diagnostics. This audit does not execute generators or claim every language/TFM emits each diagnostic identically.
