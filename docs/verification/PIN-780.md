## Inspect what an agent receives

Adapted from [MCP Inspector](../inspect-guidance.md). Requires PowerShell 7,
SDK 10.0.402 and Node 22.19+. Setup needs network; the server serves embedded
guidance offline. This exact block is tested from C:\Windows.

```powershell
& {
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-780-04-008-safe-static-subtree-caching'
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  $node = 'C:\Program Files\nodejs\node.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
  $inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $list = & $node $inspector --cli --format json --quiet --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="11.0"' --tool-arg query=static-subtree-cache -- $dotnet $server mcp | ConvertFrom-Json
  $list.result.structuredContent.recipes | Format-List id, title, goal
  if (@($list.result.structuredContent.recipes).Count -ne 1) { throw 'Expected one cache recipe' }
  $detail = & $node $inspector --cli --format json --quiet --method tools/call --tool-name get_recipe --tool-arg 'targetVersion="11.0"' --tool-arg id=blazor.cache-static-subtree -- $dotnet $server mcp | ConvertFrom-Json
  $recipe = $detail.result.structuredContent.recipe
  if (-not $recipe.markdown -or $recipe.markdown.Contains('{{snippet:') -or $recipe.edition -ne '11.0') { throw 'Incomplete cache recipe' }
  $recipe | Format-List id, edition, stability
  $recipe.markdown
  $recipe.applicability.routes | ConvertTo-Json -Depth 15
}
```

Expect blazor.cache-static-subtree, reusable title/goal, complete original
comparison, edition 11.0 and explicit SSR/user/provider constraints. Empty body,
unresolved snippet, wrong edition or missing recipe fails. Each Inspector call
initializes and closes the real stdio server.
