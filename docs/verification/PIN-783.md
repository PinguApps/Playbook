## Inspect what an agent receives

Adapted from [the Inspector walkthrough](../inspect-guidance.md). Requires
PowerShell 7, .NET SDK 10.0.402 and Node 22.19+. Setup is online; the real built
stdio server reads embedded content offline. The exact block below is verified
from the unrelated directory C:\Windows. It displays discovery ID/title/goal,
complete Markdown, edition and all applicability fields. Expect one stable
11.0 recipe with both original comparisons, Virtualize/rendered/fixed-height
requirements, default overscan 3 and RC2's removal of ASP0030. Missing discovery,
an unresolved snippet or a wrong edition fails. Each Inspector call starts and
closes the real stdio server.

```powershell
& {
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-783-04-011-virtualized-quickgrid-row-positioning'
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  $node = 'C:\Program Files\nodejs\node.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
  $inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $list = & $node $inspector --cli --format json --quiet --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="11.0"' --tool-arg query=grid-position -- $dotnet $server mcp | ConvertFrom-Json
  $entries = @($list.result.structuredContent.recipes)
  if ($entries.Count -ne 1 -or $entries[0].id -ne 'blazor.reveal-grid-row') { throw 'Missing grid discovery' }
  $entries | Format-List id, title, goal
  $response = & $node $inspector --cli --format json --quiet --method tools/call --tool-name get_recipe --tool-arg 'targetVersion="11.0"' --tool-arg id=blazor.reveal-grid-row -- $dotnet $server mcp | ConvertFrom-Json
  $recipe = $response.result.structuredContent.recipe
  if ($recipe.edition -ne '11.0' -or -not $recipe.markdown -or $recipe.markdown.Contains('{{snippet:')) { throw 'Incomplete grid detail' }
  $recipe | Format-List id, edition, stability
  $recipe.markdown
  $recipe.applicability.routes | ConvertTo-Json -Depth 15
}
```
