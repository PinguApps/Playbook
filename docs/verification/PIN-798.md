## Original consumers and source reconciliation

BrackenMenu contains four original real projects: .NET 10 and 11 Host/Client pairs.
Both pairs support the static shell with a live Server confirmation and a global
WebAssembly layout. The host owns `/bracken/`, its document, CSP and static assets.
The client uses `StaticWebAssetProjectMode=Default`. The complete returned body
contains 50 named files: project/pin/build boundaries, imports/namespaces, root
document, routes, layouts, CSS, JS, boot scripts and policy configuration.

SDKs are 10.0.402 / 11.0.100-rc.2.26504.105; target/language modes are net10.0/C#14
and net11.0/C#15. WebAssembly packages and SDK assets are 10.0.13 / matching RC2.
No required workload, provider or external service is declared. Installed workload
inventory is retained in compilation records and is not claimed empty. All sample
dependencies remain manually pinned behind their own build/package boundary;
root .NET 10 consumers and Renovate permissions remain unchanged.

[Official-source fingerprints](PIN-798.sources.json) distinguish raw pinned ASP.NET
source from actual installed template archives. The exact template directory is
`BlazorWeb-CSharp/BlazorWebCSharp.1/Components/Layout`. The RC2 archive and pinned
source use a custom element with connection/disconnection listener lifetime; the
current migration guide describes a simpler global handler. These are semantically
related guidance, not byte-identical implementations. The actual .NET 10 archive
contains its inline onclick and no NavMenu module. Bracken's markup, scoped old
handler, component/module and fictional trail example were authored independently.

The current host removes the handler hash and unsafe-hashes code entirely. Its
enforcing header uses script-src-attr 'none'. Trusted app/framework scripts,
WebAssembly compilation and local circuit connections remain allowed separately.
ES modules, ES2022 private fields, custom elements and Element.closest are explicit
browser requirements. No experimental API opt-in or GA claim is made.
