## RC2 source reconciliation

The ticket, source SPEC and approved proposal require **stable column
identifiers**, not a specific API spelling. Actual RC2 QuickGrid has no
`ColumnId` property: metadata inspection returns false and an actual compile
assigning it to PropertyColumn rejects CS1061. QueryParameterNameOptions and
Title exist. [API evidence](PIN-781.api.evidence.json) records the package identity
and bounded diagnostic commands.

The reviewed pinned source uses `column.Title` for URL sort values and matches
that value during restoration. The supported implementation freezes Title as
`code`/`priority` and places separately editable visible captions in
HeaderTemplate. Actual static requests with alternative headings and live
interactive heading changes retain the same keys and rows. No dedicated API is
invented and no capability criterion is removed. A changed key still needs a
bookmark migration. Source commit 4a70870818bf5662f21b0c28f9a8c267dccb77f0 is
review evidence; the NuGet assembly's informational-version source commit could
not be fetched through the raw-source URL, so that exact-source retrieval is
not claimed. Real artifact compilation and execution govern compatibility.

The default .NET 10 interactive controls remain valid for in-memory views.
Its comparison application explicitly implements URL sorting/paging and anchor
navigation instead. The .NET 11 application delegates restoration and pagination
to QuickGrid/QueryParameterNameOptions/Paginator. Custom headers on both targets
subscribe to LocationChanged: real browser testing caught stale header URLs
after another grid navigated; the fixed helper regenerates links and detaches
its subscription at disposal.

## Inspect what an agent receives

Requires PowerShell 7, SDK 10.0.402 and Node 22.19+. Setup is online;
the built stdio server reads embedded content offline. Adapted from
[the Inspector walkthrough](../inspect-guidance.md). Execute from any directory:

```powershell
& {
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-781-04-009-author-url-restored-quickgrid-state'
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  $node = 'C:\Program Files\nodejs\node.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
  $inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  & $node $inspector --cli --format json --quiet --method tools/list -- $dotnet $server mcp
  $call = { param($tool, $argument)
    & $node $inspector --cli --format json --quiet --method tools/call --tool-name $tool --tool-arg 'targetVersion="11.0"' --tool-arg $argument -- $dotnet $server mcp | ConvertFrom-Json
  }
  $list = (& $call list_recipes 'query=workshop-views').result.structuredContent
  if (@($list.recipes).Count -ne 1) { throw 'Expected one grid-view recipe' }
  $list.recipes | Format-List id, title, goal
  $recipe = (& $call get_recipe 'id=blazor.share-grid-view').result.structuredContent.recipe
  if ($recipe.edition -ne '11.0' -or -not $recipe.markdown -or $recipe.markdown.Contains('{{snippet:')) { throw 'Incomplete recipe' }
  $recipe | Format-List id, edition, stability
  $recipe.markdown
  $recipe.applicability.routes | ConvertTo-Json -Depth 15
}
```

Expect exactly list_recipes/get_recipe discovery, the reusable ID/title/goal,
complete original older/newer Markdown and explicit QuickGrid/static/interactive
requirements. Title is the stable RC2 key, not an invented ColumnId property.
Each Inspector call starts and closes the real server. Package harness evidence
is separate from this built-server inspection.
