## Inspect what an agent receives

Requires PowerShell 7.3+, the pinned host SDK and Node 22.19+. Setup installs pinned Inspector dependencies into ignored artifacts. These are the actual tested commands, adapted from [the MCP Inspector walkthrough](../inspect-guidance.md). Both real built-server tools are called; Playbook serves embedded content. Each call closes its server automatically.

```powershell
& {
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  Set-Location V:\_worktrees\Playbook\t3-8e02f3bf
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & 'C:\Program Files\nodejs\npm.cmd' install --prefix ./artifacts/inspector-2.11.0 --no-audit --no-fund --package-lock=false @modelcontextprotocol/inspector@2.11.0
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $inspector = (Resolve-Path ./artifacts/inspector-2.11.0/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $cli = @('--cli', '--format', 'json', '--quiet')
  $catalogue = & 'C:\Program Files\nodejs\node.exe' $inspector @cli --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="11.0"' --tool-arg 'languages=["fsharp"]' -- $dotnet $server mcp | ConvertFrom-Json
  $catalogue.result.structuredContent.recipes | Format-List id, title, goal, stability
  foreach ($id in @('fsharp.compose-records', 'fsharp.construct-records', 'json.serialize-fsharp-unions', 'fsharp.preserve-interpolation-culture', 'fsharp.format-without-reflection')) {
    $response = & 'C:\Program Files\nodejs\node.exe' $inspector @cli --method tools/call --tool-name get_recipe --tool-arg "id=$id" --tool-arg 'targetVersion="11.0"' -- $dotnet $server mcp | ConvertFrom-Json
    $recipe = $response.result.structuredContent.recipe
    $recipe | Format-List id, edition, introducedIn
    $recipe.markdown | Show-Markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 15
  }
}
```

Expect five F# discovery summaries with ID, reusable title, goal and stability. Every detail has edition/introduction **11.0**, full original older/newer examples and explicit applicability. Only `fsharp.construct-records` is experimental and requires preview. Union guidance must show reflection-only/source-generation/trimming/AOT restrictions; diagnostics must show culture or contained-value requirements. Missing body/applicability, unresolved snippet tokens or a silently compatible .NET 10 edition is a failure.
