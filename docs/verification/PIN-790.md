## Test changes

The source samples, compilation records and four actual browser reports above are
inspectable now. To run the newer local sample in a terminal:

```powershell
Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-790-04-018-deliberate-blazor-circuit-transport-policy'
$env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
Set-Location -LiteralPath './samples/net11.0/LockhouseSessions'
& 'C:\Users\pingu\.dotnet-playbook-11\dotnet.exe' run --project LockhouseSessions.csproj -c Release --no-launch-profile -- --urls http://localhost:5791 --environment Development
```

The last command occupies the terminal. Open http://localhost:5791/sign-in and
immediately relay a cargo note. Expect a receipt and identical returned text,
WebSockets-only negotiation and a 101 circuit upgrade. After the 25-second ticket
expires, expect Disconnected and 401 for a new negotiation. Run the saved browser
test expression immediately after a fresh `/sign-in` for its exact assertions;
expect PASS and 27,648 returned characters. A fallback transport, mismatched text,
continued connection with closure enabled or successful new expired-cookie
connection is a failure.

Stop with Ctrl+C. Add `--CloseOnExpiry false` to the arguments, restart and sign in
again: after expiry, receipt 2 must still succeed on the existing circuit while a
new negotiation remains 401. Repeat with `samples/net10.0/LockhouseSessions`,
`C:\Program Files\dotnet\dotnet.exe` and port 5790. These are Development-only,
loopback, fictional sign-in fixtures. Keys/data live only in the process; stop
the terminal to clean up. This does not change an account or deployed service.
