To refresh records after an actual input change, follow the [capture commands](../contributing.md#declare-inputs-then-run-the-real-commands). They write sample evidence files; unchanged documentation work does not need refreshed committed compilation records. To inspect this exact package, run the [fresh local-feed/cache installation block](../contributing.md#inspect-the-development-package), then:

```powershell
Set-Location V:\_worktrees\Playbook\t3-ad354b88
$server = (Resolve-Path ./artifacts/manual-tool/playbook.exe).Path
$inspector = @('--yes', '@modelcontextprotocol/inspector@2.11.0', '--cli', '--format', 'json', '--quiet')
Push-Location $env:TEMP
try {
    $list = npx @inspector --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="10.0"' -- $server mcp | ConvertFrom-Json
    $list.result.structuredContent.recipes | Format-List id, title, goal
    $detail = npx @inspector --method tools/call --tool-name get_recipe --tool-arg id=csharp.validate-property-assignment --tool-arg 'targetVersion="10.0"' -- $server mcp | ConvertFrom-Json
    $recipe = $detail.result.structuredContent.recipe
    $recipe.markdown | Show-Markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 10
    $recipe.evidence | Format-List role, sample, target, sdk, language, command, freshness
    $recipe.humanProof | Format-List
}
finally { Pop-Location }
```

Expect `csharp.validate-property-assignment`, title **Normalize and validate properties with the C# field keyword**, and a reusable `goal` describing normalization/validation without a separate backing-field declaration. Full Markdown includes both original warehouse implementations and numbered migration steps, with no unresolved snippet tokens. Applicability shows primary .NET 10/C# 14 requirements and the separate optional SDK 11 route; four exact evidence records remain `freshness: current`, including the comparison and RC paths. `humanProof.status` is `not-required` for this portable behavior. Missing Markdown, an SDK 11 requirement on the primary route or a GA-tested claim is a failure. Each Inspector call starts and shuts down its server automatically.

The ordinary package is an unpublished development artifact. Remove the optional manual install/feed when finished, or use new directory names on the next run. No global tool or persistent environment setting is changed.
