## Inspect what an agent receives

Use PowerShell 7, SDK 10.0.402 and the absolute Node executable below. Setup/build
is online; retrieval uses embedded guidance without source-site access. This exact
block was tested from unrelated **C:\Windows**. The [Inspector receipt](PIN-797.inspector.evidence.json)
records the exact script/response/body hashes. Its built server DLL is byte-identical
to the actual tested ordinary package DLL.

```powershell
Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-797-04-025-collect-component-activity-from-the-browser'
$ErrorActionPreference = 'Stop'
$PSNativeCommandUseErrorActionPreference = $true
$env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
$dotnet = 'C:\Program Files\dotnet\dotnet.exe'
$node = 'C:\Program Files\nodejs\node.exe'
New-Item -ItemType Directory -Path ./artifacts/pin797 -Force | Out-Null
& $dotnet build ./src/PinguApps.Playbook -c Release -p:Version=0.0.0-pin797.6 -p:EnableSourceLink=false -p:IncludeSourceRevisionInInformationalVersion=false -p:EnableSourceControlManagerQueries=false
& $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
$inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
$server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
$call = { param($tool, $argument)
  & $node $inspector --cli --format json --quiet --method tools/call --tool-name $tool --tool-arg 'targetVersion="11.0"' --tool-arg $argument -- $dotnet $server mcp | ConvertFrom-Json
}
$entry = (& $call list_recipes 'query=loom-activity').result.structuredContent.recipes
if ($entry.id -ne 'blazor.observe-browser-components') { throw 'Missing discovery' }
$entry | Format-List id, title, goal
$recipe = (& $call get_recipe 'id=blazor.observe-browser-components').result.structuredContent.recipe
if ($recipe.edition -ne '11.0' -or -not $recipe.markdown -or $recipe.markdown.Contains('{{snippet:')) { throw 'Incomplete recipe' }
$recipe | Format-List id, edition, stability
$recipe.markdown
$recipe.applicability | ConvertTo-Json -Depth 30
$recipe.sources | Format-Table
$recipe.evidence | Select-Object sample, target, sdk, kind, freshness | Format-Table
[IO.File]::WriteAllText((Join-Path (Get-Location) 'artifacts/pin797/inspected-recipe.json'), ($recipe | ConvertTo-Json -Depth 50).Replace("`r`n", "`n") + "`n")
```
