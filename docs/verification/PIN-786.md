## Inspect what an agent receives

Adapted from [the Inspector walkthrough](../inspect-guidance.md). Requires
PowerShell 7, SDK 10.0.402 and the installed Node.js at the paths below. Setup
restores dependencies online; the built server serves embedded content. The
entire block must be verified from an unrelated directory such as C:\Windows.

```powershell
& {
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-786-04-014-restrictive-csp-virtual-lists'
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  $node = 'C:\Program Files\nodejs\node.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
  $inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $list = & $node $inspector --cli --format json --quiet --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="11.0"' --tool-arg query=beacon-csp -- $dotnet $server mcp | ConvertFrom-Json
  if (@($list.result.structuredContent.recipes).Count -ne 1) { throw 'Expected one CSP recipe' }
  $list.result.structuredContent.recipes | Format-List id, title, goal
  $detail = & $node $inspector --cli --format json --quiet --method tools/call --tool-name get_recipe --tool-arg 'targetVersion="11.0"' --tool-arg id=blazor.virtualize-under-csp -- $dotnet $server mcp | ConvertFrom-Json
  $recipe = $detail.result.structuredContent.recipe
  $recipe | Format-List id, edition, stability
  $recipe.markdown
  $recipe.applicability | ConvertTo-Json -Depth 20
}
```

Expect one ID/title/goal, edition 11.0, the complete .NET 10/11 comparison and all
applicability fields. Detail must retain strict style directives, older exception,
trusted-CSSOM distinction, actual sample scope and RC2/consumer-browser limits.
An unresolved snippet, omitted body or requirement is a failure. Every Inspector
call starts and cleanly closes the real stdio server.
