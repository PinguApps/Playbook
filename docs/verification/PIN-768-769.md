## Inspect what an agent receives

The block below follows [the MCP Inspector walkthrough](../inspect-guidance.md).
It selects this exact checkout before relative paths and calls the actual
built server. Build/package restore and pinned Inspector setup need network
access; guidance retrieval itself is embedded. PowerShell 7, the root SDK,
Node 22.19+ and the stated executable paths are prerequisites.

```powershell
Set-Location -LiteralPath 'V:\_worktrees\Playbook\t3-15b68ce5'
$ErrorActionPreference = 'Stop'
$PSNativeCommandUseErrorActionPreference = $true
$env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
$env:DOTNET_CLI_TELEMETRY_OPTOUT = '1'
$dotnet = 'C:\Program Files\dotnet\dotnet.exe'
$node = 'C:\Program Files\nodejs\node.exe'
& $dotnet build ./src/PinguApps.Playbook -c Release
& $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector-2.11.0 --ignore-scripts --no-audit --no-fund --package-lock=false @modelcontextprotocol/inspector@2.11.0
$server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
$inspector = (Resolve-Path ./artifacts/inspector-2.11.0/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
$cli = @('--cli', '--format', 'json', '--quiet')
$target = 'targetVersion="11.0"'
$list = & $node $inspector @cli --method tools/call --tool-name list_recipes --tool-arg $target --tool-arg query=build-package-policy -- $dotnet $server mcp | ConvertFrom-Json
if ($list.result.structuredContent.recipes.Count -ne 4) { throw 'Expected four policy recipes.' }
$list.result.structuredContent.recipes | Format-List id, title, goal
foreach ($summary in $list.result.structuredContent.recipes) {
    $response = & $node $inspector @cli --method tools/call --tool-name get_recipe --tool-arg "id=$($summary.id)" --tool-arg $target -- $dotnet $server mcp | ConvertFrom-Json
    $recipe = $response.result.structuredContent.recipe
    $recipe | Format-List id, edition
    $recipe.markdown | Show-Markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 15
}
```

Expect exactly four ID/title/goal summaries, complete original comparisons,
target-11 edition/applicability and the RC2 restrictions above. No unresolved
snippet token may remain. Target-10 detail for each ID must return
no_applicable_edition. Installed-package checks additionally compare the entire
body with independently embedded canonical sources, full selection constraints
and matching JSON-text/structured representations using the existing isolated
feed/cache, unrelated-directory and real stdio lifecycle harness.
