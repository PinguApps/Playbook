## Inspect what an agent receives

Adapted from [the Inspector walkthrough](../inspect-guidance.md). Requires
PowerShell 7, SDK 10.0.402 and Node 22.19+. Inspector setup is online; the built
server serves its embedded guidance offline. The actual paths are literal.
This exact block is tested from C:\Windows.

```powershell
& {
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-785-04-013-virtual-list-item-reveal'
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  $node = 'C:\Program Files\nodejs\node.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
  $inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $call = { param($tool, $argument)
    & $node $inspector --cli --format json --quiet --method tools/call --tool-name $tool --tool-arg 'targetVersion="11.0"' --tool-arg $argument -- $dotnet $server mcp | ConvertFrom-Json
  }
  $list = & $call list_recipes 'query=lantern-queue'
  $entry = @($list.result.structuredContent.recipes)
  if ($entry.Count -ne 1 -or $entry[0].id -ne 'blazor.reveal-virtual-item') { throw 'Missing reveal discovery' }
  $entry | Format-List id, title, goal
  $recipe = (& $call get_recipe 'id=blazor.reveal-virtual-item').result.structuredContent.recipe
  if ($recipe.edition -ne '11.0' -or -not $recipe.markdown -or $recipe.markdown.Contains('{{snippet:')) { throw 'Incomplete recipe' }
  $recipe | Format-List id, edition, stability
  $recipe.markdown
  $recipe.applicability.routes | ConvertTo-Json -Depth 20
  $recipe.sources | Format-Table
  $recipe.evidence | Format-List
}
```

Expect ID `blazor.reveal-virtual-item`, title **Reveal a virtual list item**, goal
**Jump to a chosen item in a virtualized list.**, edition 11.0, stable API status,
full canonical older/newer/provider/host/document bodies and complete
applicability. Requirements explicitly preserve interactive rendering, bounds,
provider timing and the RC2 evidence limit. Missing guidance, unresolved snippet
tokens or a wrong edition fails. Each call closes its real stdio server.
