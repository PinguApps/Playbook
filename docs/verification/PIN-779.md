## Inspect what an agent receives

The PowerShell block below was tested from unrelated directory `C:\`, following
[the real stdio Inspector walkthrough](../inspect-guidance.md). Requires installed
SDK 10.0.402, PowerShell 7 and Node 22.19+ at the shown paths. Setup downloads pinned
Inspector dependencies into ignored artifacts, with npm lifecycle scripts disabled;
guidance retrieval itself needs no network. Each Inspector call closes its server.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $PSNativeCommandUseErrorActionPreference = $true
    Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-779-04-007-offer-a-single-parameter-for-alternative-ui-values'
    $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
    $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
    $node = 'C:\Program Files\nodejs\node.exe'
    & $dotnet build ./src/PinguApps.Playbook -c Release
    & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector-2.11.0 --ignore-scripts --no-audit --no-fund --package-lock=false @modelcontextprotocol/inspector@2.11.0
    $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
    $inspector = (Resolve-Path ./artifacts/inspector-2.11.0/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
    $cli = @('--cli', '--format', 'json', '--quiet')
    & $node $inspector @cli --method tools/list -- $dotnet $server mcp
    $list = & $node $inspector @cli --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="11.0"' --tool-arg query=seed-labels -- $dotnet $server mcp | ConvertFrom-Json
    $list.result.structuredContent.recipes | Format-List id, title, goal
    $response = & $node $inspector @cli --method tools/call --tool-name get_recipe --tool-arg id=blazor.accept-alternative-parameter-shapes --tool-arg 'targetVersion="11.0"' -- $dotnet $server mcp | ConvertFrom-Json
    $recipe = $response.result.structuredContent.recipe
    $recipe | Format-List id, edition, title, goal
    $recipe.markdown | Show-Markdown
    $recipe.applicability | ConvertTo-Json -Depth 20
}
```

Expected: exactly `list_recipes` and `get_recipe`, the stable ID with its reusable
title and goal, complete original Markdown and all applicability routes. Detail
selects edition/target **11.0**, C# **15.0**, matching ASP.NET Core assets and
explicit JSON/fragment restrictions; no unresolved snippet markers. Missing content,
wrong target/edition or absent constraints fails the handoff. This block exercises
the built server; the separate installed harness establishes the actual package
boundary. Neither reading path proves WebAssembly/Auto or GA behavior.
