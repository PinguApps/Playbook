The language sources require preview plus `updated-memory-safety-rules`; these remain explicit experimental opt-ins. Current-main C# 16 compatibility notes do not establish stable C# 15 behavior. The actual RC2 compiler/reference/runtime artifacts are the authority for this bounded edition:

- A forced rebuild with unsafe syntax and `AllowUnsafeBlocks=false` fails **CS0227**. Changing switches without rebuilding initially reused an incremental output, so every compiler probe now uses `-t:Rebuild`.
- Pointer declaration, address-taking and pinning alone compile and execute with the setting false in preview. Dereference without a context fails **CS9360**.
- The real `ReadOnlySpan<byte>(void*, int)` constructor still requires an unsafe context (**CS9362**) and executes with an explicit acknowledgement. Therefore the library overview's blanket project-setting/annotation-removal headline is not a usable instruction for these artifacts. No annotation-removal conclusion is extrapolated to the entire API list.
- An opted-in external consumer reads the raw public member only in an unsafe context. Private access fails **CS0122**. An unsafe member's body separately requires a context (**CS9360**).
- A layout field without a safety decision fails **CS9392**; the canonical `safe` field compiles and is read/written in the actual sample. Missing preview fails **CS8652**. A pointer-free unsafe member needs caller acknowledgement under the new rules, while legacy rules permit the same call.
- Reflection over the built sample observes **module** `System.Runtime.CompilerServices.MemorySafetyRulesAttribute(2)` and member `System.Diagnostics.CodeAnalysis.RequiresUnsafeAttribute`. The current documentation describes an assembly marker; the report and guidance record the actual module placement.

Official sources are declared in recipe metadata and served offline as references: [C# preview](https://learn.microsoft.com/en-us/dotnet/csharp/whats-new/csharp-15#memory-safety), [compiler options](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/compiler-options/language#enable-the-updated-memory-safety-rules), [language design](https://github.com/dotnet/csharplang/blob/main/proposals/unsafe-evolution.md), [canonical RC1 notes](https://github.com/dotnet/core/blob/ffed591b0fb8f9aab50ecc28f2c765049fb28d8f/release-notes/11.0/preview/rc1/csharp.md), and [the disputed library overview](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-11/libraries#unsafe-api-accessibility). ## Inspect what an agent receives

The block selects the PIN-715 worktree explicitly, follows [the MCP Inspector walkthrough](../inspect-guidance.md), installs pinned Inspector dependencies under ignored artifacts and launches the real built server. It does not need the sample SDKs or a network fetch for recipe content. Each call closes its server automatically.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $PSNativeCommandUseErrorActionPreference = $true
    Set-Location -LiteralPath 'V:\_worktrees\Playbook\t3-b5ed3010'
    $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
    $dotnet = (Get-Command dotnet -CommandType Application).Source
    $node = (Get-Command node -CommandType Application).Source
    $npm = Join-Path (Split-Path $node) 'npm.cmd'
    & $dotnet build ./src/PinguApps.Playbook -c Release
    & $npm install --prefix ./artifacts/inspector-2.11.0 --no-audit --no-fund --package-lock=false @modelcontextprotocol/inspector@2.11.0
    $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
    $inspector = (Resolve-Path ./artifacts/inspector-2.11.0/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
    $cli = @('--cli', '--format', 'json', '--quiet')
    $list = & $node $inspector @cli --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="11.0"' --tool-arg 'query=unsafe memory boundaries' -- $dotnet $server mcp | ConvertFrom-Json
    $list.result.structuredContent.recipes | Format-List id, title, goal
    $response = & $node $inspector @cli --method tools/call --tool-name get_recipe --tool-arg id=csharp.audit-memory-boundaries --tool-arg 'targetVersion="11.0"' -- $dotnet $server mcp | ConvertFrom-Json
    $recipe = $response.result.structuredContent.recipe
    $recipe | Format-List id, edition, introducedIn, stability
    $recipe.markdown | Show-Markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 15
}
```
