## Inspect what an agent receives

Adapted from [MCP Inspector guidance](../inspect-guidance.md). PowerShell 7.3+, host SDK 10.0.402 and Node 22.19+ are required; Inspector setup needs network, whereas the built server's content retrieval does not. Run from any unrelated directory: the literal location command selects this task's checkout. These short-lived calls display discovery ID/title/goal, full Markdown, edition and selected applicability; nothing remains running.

```powershell
& {
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\t3-c967a5c3'
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & 'C:\Program Files\nodejs\npm.cmd' install --prefix ./artifacts/inspector-2.11.0 --ignore-scripts --no-audit --no-fund --package-lock=false @modelcontextprotocol/inspector@2.11.0
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $inspector = (Resolve-Path ./artifacts/inspector-2.11.0/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $ids = @('stream-json-lines','reuse-writer','configure-generic-contracts','retrieve-typed-metadata','generate-private-contracts','preserve-omitted-initializers','bind-reference-constructors','configure-member-conventions','use-numeric-collection-contracts','describe-binary-schema','reject-malformed-contracts') | ForEach-Object { "json.$_" }
  $cli = @('--cli','--format','json','--quiet')
  $list = & 'C:\Program Files\nodejs\node.exe' $inspector @cli --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="11.0"' --tool-arg query=json --tool-arg limit=50 -- $dotnet $server mcp | ConvertFrom-Json
  $list.result.structuredContent.recipes | Where-Object id -In $ids | Format-List id, title, goal
  foreach ($id in $ids) {
    $result = & 'C:\Program Files\nodejs\node.exe' $inspector @cli --method tools/call --tool-name get_recipe --tool-arg "id=$id" --tool-arg 'targetVersion="11.0"' -- $dotnet $server mcp | ConvertFrom-Json
    $recipe = $result.result.structuredContent.recipe
    $recipe | Format-List id, edition, introducedIn
    $recipe.markdown | Show-Markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 15
  }
  $retained = & 'C:\Program Files\nodejs\node.exe' $inspector @cli --method tools/call --tool-name get_recipe --tool-arg id=json.reject-malformed-contracts --tool-arg 'targetVersion="10.0"' -- $dotnet $server mcp | ConvertFrom-Json
  $retained.result.structuredContent.recipe | Format-List id, edition, markdown, applicability
}
```
