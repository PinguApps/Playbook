## Inspect what an agent receives

Adapted from [MCP Inspector guidance](../inspect-guidance.md). Requires PowerShell 7.3+, host SDK 10.0.402 and Node 22.19+. Inspector setup needs network; Playbook retrieval is local. The literal Set-Location selects the correct checkout from an unrelated directory. Every server is short-lived.

```powershell
& {
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\t3-e8046a4f'
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & 'C:\Program Files\nodejs\npm.cmd' install --prefix ./artifacts/inspector-2.11.0 --ignore-scripts --no-audit --no-fund --package-lock=false @modelcontextprotocol/inspector@2.11.0
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $inspector = (Resolve-Path ./artifacts/inspector-2.11.0/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $cli = @('--cli','--format','json','--quiet')
  foreach ($target in @('10.0','11.0')) {
    $targetArg = 'targetVersion="' + $target + '"'
    $list = & 'C:\Program Files\nodejs\node.exe' $inspector @cli --method tools/call --tool-name list_recipes --tool-arg $targetArg --tool-arg query=linq -- $dotnet $server mcp | ConvertFrom-Json
    $list.result.structuredContent.recipes | Format-List id, title, goal
    foreach ($summary in $list.result.structuredContent.recipes) {
      $result = & 'C:\Program Files\nodejs\node.exe' $inspector @cli --method tools/call --tool-name get_recipe --tool-arg "id=$($summary.id)" --tool-arg $targetArg -- $dotnet $server mcp | ConvertFrom-Json
      $recipe = $result.result.structuredContent.recipe
      $recipe | Format-List id, edition, introducedIn
      $recipe.markdown | Show-Markdown
      $recipe.applicability.routes | ConvertTo-Json -Depth 15
    }
  }
}
```

Expected: target 10 lists `linq.retain-unmatched-rows` and `linq.transform-async-stream`, edition 10.0. Target 11 lists those unchanged editions plus `linq.reconcile-all-rows`, edition 11.0. Every detail displays complete original older/newer examples, numbered migration, constraints, evidence and only the selected target's applicability. Missing body/goal/applicability, unresolved snippet placeholders or a target-10 FullJoin result is a failure. Queryable restrictions and cooperative cancellation limits remain explicit offline.
