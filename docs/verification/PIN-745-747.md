## Acceptance mapping and accepted RC qualification

All targets' criteria 1–5 map to six original goal-based 11.0 editions, six actual
.NET 10/11 sample projects, complete offline metadata/Markdown, canonical-source
snippets, official references, input-hashed evidence, an updated source register
and the existing packed-tool/isolated-feed/cache stdio harness. The comparison
projects do not add any .NET 10 foundation or advertise an unverified older-target
route. The host/transport/public MCP interface is unchanged.

- **PIN-745 criteria 6–7:** ConfigurationLifecycle binds BerthLimit=12 and preserves
  SessionCredential's runtime value despite hostile matching input. The older
  allowlist and newer ConfigurationIgnore solve the same goal. Real cancellation
  change tokens and task barriers verify serial refreshes, coalesced intermediate
  notifications, caught async failure and later success. RC2 checks synchronous
  delegate exceptions and work completing after subscription disposal. The
  unobserved-fault policy is source evidence, not a GC-event execution claim.
- **PIN-746 criteria 6–7:** OptionsStartup runs real Generic Host startup with
  constructor-injected capacity rules and async permit acceptance/rejection.
  RC2 checks custom IAsyncStartupValidator, named dual validation, generated range
  rejection, seeded default/monitor caches, synchronous pre-start/snapshot/factory
  failures, async-only plus succeeding sync validators and actual monitor reload
  rejection with zero change notifications. Test-OptionsStartup.ps1 compiles the
  explicit/generated conflict to SYSLIB1205, restores generated ownership and
  builds/runs the fixed path. Custom factory/default-IOptions/legacy-validator
  limits remain clearly labelled pinned-source restrictions.
- **PIN-747 criteria 6–7:** CacheEntries observes actual hits/misses, entry count,
  estimated size and compaction eviction, with the RC2 cache/result tags. A direct
  MemoryCache entry declares twelve rows and the cache reports twelve application
  units, not process memory. HybridCache's context factory determines local
  expiry; a hit avoids another load, and expiry causes another factory execution.

**User decision, 21 October 2026:** after the requested-24/observed-12 LocalSize
failure was explained, Pingu directed: “We should go with the .net docs, for
RC's.” The target is GA. The documented LocalSize API therefore remains in the
GA-targeted example, with an explicit warning in discovery, detail and execution
output that HybridCache 10.11.0 ignores it in this tested composition. This is
permission to deliver the PR with that known RC qualification, not proof of
custom HybridCache sizing or a promise that GA will fix it. The regression check
asserts the observed mismatch so a changed implementation forces re-evaluation.
GA reconciliation must establish the intended contract before claiming it works.
No missing compilation or required Human proof is hidden by this decision.

global installation, PATH modification or account is needed.

```powershell
& {
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\t3-fc99afd1'
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  $node = 'C:\Program Files\nodejs\node.exe'

  $inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $call = { param($tool, $argument)
    & $node $inspector --cli --format json --quiet --method tools/call --tool-name $tool --tool-arg 'targetVersion="11.0"' --tool-arg $argument -- $dotnet $server mcp | ConvertFrom-Json
  }
  $list = & $call list_recipes 'query=configuration-options-cache'
  $list.result.structuredContent.recipes | Format-List id, title, goal

    $recipe.markdown | Show-Markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 15
  }
}
```
