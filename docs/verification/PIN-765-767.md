## Inspect what an agent would receive

This is a proposed adaptation of [the MCP Inspector walkthrough](../inspect-guidance.md),
**not a tested command block**. It has not been run from this or an unrelated
directory. The literal Set-Location selects the assigned checkout before any
relative path. Nothing below requires Podman or sends consumer telemetry; it
would build the documentation host and retrieve embedded guidance only.

Requires PowerShell 7, the root SDK 10.0.402, Node 22.19+ and network access for
SDK package restore/pinned Inspector setup. No .NET 11 sample build is performed
by this block. It changes only the invoking process's guard variables, creates
ignored local build/client artifacts, and closes each stdio session automatically.

```powershell
Set-Location -LiteralPath 'V:\_worktrees\Playbook\t3-e4cc4784'
$ErrorActionPreference = 'Stop'
$PSNativeCommandUseErrorActionPreference = $true
$env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
$env:DOTNET_CLI_TELEMETRY_OPTOUT = '1'
$dotnet = 'C:\Program Files\dotnet\dotnet.exe'
$node = 'C:\Program Files\nodejs\node.exe'
& $dotnet build ./src/PinguApps.Playbook -c Release
& $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector-2.11.0 --ignore-scripts --no-audit --no-fund --package-lock=false @modelcontextprotocol/inspector@2.11.0
$server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
$inspector = (Resolve-Path ./artifacts/inspector-2.11.0/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
$cli = @('--cli', '--format', 'json', '--quiet')
$target = 'targetVersion="11.0"'
$list = & $node $inspector @cli --method tools/call --tool-name list_recipes --tool-arg $target --tool-arg query=sdk-build-artifacts -- $dotnet $server mcp | ConvertFrom-Json
$list.result.structuredContent.recipes | Format-List id, title, goal
foreach ($summary in $list.result.structuredContent.recipes) {
    $response = & $node $inspector @cli --method tools/call --tool-name get_recipe --tool-arg "id=$($summary.id)" --tool-arg $target -- $dotnet $server mcp | ConvertFrom-Json
    $recipe = $response.result.structuredContent.recipe
    $recipe | Format-List id, edition
    $recipe.markdown | Show-Markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 15
    $recipe.evidence | Format-List kind, role, scope, sdkInfo, output
    $recipe.humanProof | Format-List
}
```
