## Actual artifacts and operations

- KeyMaterial: independent .NET 10/11 projects, no packages. The previous example
  uses P-256, fixed-time equal-length comparison and RFC 5649 KWP. The new example
  uses X25519/HKDF, repeated-byte FixedTimeEquals and RFC 3394 KW. Checks cover
  independent agreement, public SPKI/private PKCS#8 containers, malformed and
  low-order input, first/middle/last nonzero bytes, wrong length, key recovery,
  tampering/wrong-key rejection, odd KWP sizes and an attributed RFC 3394 vector.
- PostQuantum: .NET 10 uses pure ML-KEM and RSA CMS; .NET 11 uses the selected
  ML-KEM-768/P-256 composite, classical P-256 HPKE and pure ML-KEM CMS. Public-only
  sender keys, malformed capsules, actual seal/open and ciphertext-tamper
  rejection, encoded KEM recipient type, wrong private key and unsupported
  composite CMS decryption are checked. Ephemeral certificates establish only
  local round-trip behavior, not certificate trust or message authenticity.
- SDKs: 10.0.402/C# 14.0 on Windows x64; 11.0.100-rc.2.26504.105/C# 15.0 on
  Linux x64 with OpenSSL 3.5.5. The Linux image is the existing digest-pinned
  native-capability SDK image, not a new CI lane. The authoring script copies
  exact declared inputs, restores locked packages from a read-only cache and
  builds/runs with `--network none`.
- Pkcs: exact 10.0.13 and 11.0.0-rc.2.26504.105 package versions and lockfiles,
  isolated sample CPM boundaries. The newer consumer selects
  `lib/net11.0/System.Security.Cryptography.Pkcs.dll`; its Windows runtime asset
  does not provide the demonstrated non-Windows CMS route. New sample packages
  stay author-maintained under the existing Renovate default-deny rules.

## Inspect what an agent receives

Adapted from [the MCP Inspector walkthrough](../inspect-guidance.md). Requires
PowerShell 7, .NET SDK 10.0.402 and Node 22.19+. The pinned Inspector install is
online preparation with lifecycle scripts disabled; the actual built server
returns embedded guidance over real stdio. No global tools or PATH changes.

```powershell
& {
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\t3-49e87701'
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  $node = 'C:\Program Files\nodejs\node.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
  $inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $call = { param($tool, $argument)
    & $node $inspector --cli --format json --quiet --method tools/call --tool-name $tool --tool-arg 'targetVersion="11.0"' --tool-arg $argument -- $dotnet $server mcp | ConvertFrom-Json
  }
  $list = & $call list_recipes 'query=crypto-key-contracts'
  $list.result.structuredContent.recipes | Format-List id, title, goal
  foreach ($entry in $list.result.structuredContent.recipes) {
    $recipe = (& $call get_recipe "id=$($entry.id)").result.structuredContent.recipe
    $recipe | Format-List id, edition, stability
    $recipe.markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 15
  }
}
```
