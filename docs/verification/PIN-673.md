# PIN-673: validate one packed tool on supported hosts

## Delivery and scope

The reusable validation role packs the ordinary tool once on Blacksmith Linux. Its SHA-256 manifest travels with the package to both isolated Linux consumers and the Windows/macOS consumers. The compiled Reqnroll suite is also reused, without desktop builds. Each desktop runs exactly one tagged scenario covering isolated install, help/version, real stdio initialize/tool discovery/list/get, full Markdown and applicability, embedded canonical examples, and clean shutdown. The focused Linux suite additionally exercises the separate unpublished contract fixture.

Every installation has a fresh feed, cache, store and unrelated working directory. Tests compare the installed DLL to the DLL inside the supplied archive. Consumers reject a changed manifest and mixed/wrong runtime inventories. Host tracing verifies the actual server CoreCLR path; the test runner's roll-forward option does not replace the installed command's packaged `Major` policy. Linux .NET 11 contains no .NET 10 runtime. Its explicit prerelease-selection opt-in establishes RC compatibility only.

TRX files, full server host traces and JSON package/runtime/process/shutdown records are uploaded. The final summary uses GitHub job timestamps for elapsed validation and summed validation-runner seconds, including setup and teardown. The reporting job's own duration is excluded from that in-run subtotal and must be added when auditing the completed run. Runner seconds are not billed cost; no cost saving is claimed. No native builds, UI, devices, emulators or client-by-OS matrices were added.

## Repeat the verification

Requires PowerShell 7, SDK 10.0.402, the independently pinned .NET 9/11 sample SDKs and Docker Linux containers. On Pingu's machine the additional SDKs already exist at the paths below. Temporary environment changes apply only to the current process and children.

```powershell
Set-Location V:\_worktrees\Playbook\t3-2acb46b2
pwsh ./eng/Verify.ps1 -Net9Dotnet C:\Users\pingu\.dotnet-playbook-9\dotnet.exe -Net11Dotnet C:\Users\pingu\.dotnet-playbook-11\dotnet.exe -ReleaseReady
pwsh ./eng/Test-Offline.ps1 -RuntimeMajor 10
pwsh ./eng/Test-Offline.ps1 -RuntimeMajor 11

# One local desktop smoke, using the same actual package and compiled suite.
pwsh ./eng/Test-Package.ps1 -Artifacts ./artifacts -Suite ./tests/PinguApps.Playbook.Tests/bin/Release/net10.0 -PackageVersion 1.0.0-preview.1 -Smoke
Get-Content ./artifacts/package.sha256
Get-ChildItem ./artifacts/TestResults -Recurse -Filter *.json |
  ForEach-Object { Get-Content $_.FullName -Raw | ConvertFrom-Json } |
  Select-Object package, sha256, coreClr, expectedRuntime, shutdownExitCode
```

Expect 13 scenarios in each Linux lane, exactly one in a desktop smoke, zero failures/skips, and exit code zero. Ordinary package hashes must match the manifest across lanes. Contract-fixture records have a different hash despite sharing the package filename; that synthetic package is never uploaded as `playbook-package` or published. CoreCLR paths must show .NET 10 in that lane and .NET 11 RC in the other. A mismatch, missing trace or missing/empty test set is a failure.

## Local evidence

`eng/Verify.ps1 -ReleaseReady` passed all 13 Windows installed scenarios, four real sample build/execution paths, content-validation controls and negative cases, evidence freshness, and real pack/release rejection gates. Release build: zero warnings/errors. A separate tagged Windows smoke passed in 3.35 seconds; the same ordinary package passed a tagged .NET 11-only Linux smoke in 2.31 seconds with no network or checkout mount. Altering the manifest failed before installation; selecting the .NET 11 lane on the .NET 10 machine failed the runtime-inventory gate. Formatting, whitespace checks and workflow actionlint passed.

Local ordinary package SHA-256: `b4920301beb8569436aff904bebc12bf461e7c531d048031ec511ffb3401bf0b`. Windows host trace selected `.NET 10.0.13`; Linux image inventories contain only `.NET 10.0.12` or `.NET 11.0.0-rc.2.26504.105`, respectively.
