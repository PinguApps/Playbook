## Scope and source reconciliation

Original CultureHarbour Host/Client pairs compare .NET 10 manual startup selection
with .NET 11 persisted server culture. Server request policy selects en-GB
formatting and fr-FR translations; browser runtime startup is explicitly en-US.
A separate independent mode sets both client cultures to de-DE. The .NET 11
host explicitly sets Components:UseCultureFromServer=false, even with localization
registered. Disabling transfer alone is not presented as a client culture choice.

The public WebAssemblyComponentsOptions.UseCultureFromServer API was removed
during Preview 7. The pinned RC2 source/artifacts use the configuration key and
parameterless registration. Absent/unrecognized configuration defaults to
IStringLocalizerFactory availability; true/1 and false/0 are explicit policies.
No internal options class is offered as a public callback. Source ownership and
G24 identity are retained in the Blazor disposition register and web inventory.

Pinned source `dotnet/aspnetcore@4a70870818bf5662f21b0c28f9a8c267dccb77f0`
restores component state, applies both cultures, then loads satellites before
rendering. The previous `0ef4bbfa3291b306a21e5001cb0491277bdd35bc` host loads
resources before component state; its comparison therefore selects in Program.
The existing [Blazor audit](../planning/audits/blazor.md) binds the actual SDK,
package VMR metadata and framework source revisions. Recipe sources link the
exact registration/configuration/state/host/resource files and official guidance.

Prerendered WASM in Blazor Web Apps; satellite assembly timing. This is interpreted
local development execution, without AOT, Interactive Auto/Server, production
hosting or GA execution claims. No provider, remote account/resource or required
Human-only proof is assumed. No package or resource is published.

## Inspect what an agent receives

Adapted from [the Inspector walkthrough](../inspect-guidance.md). Requires
PowerShell 7, SDK 10.0.402 and Node 22.19+ at the paths below. Setup/build needs
network access; the real stdio server reads embedded offline guidance. The block
prints discovery ID/title/goal, full Markdown, applicability and target edition.
It also saves the returned recipe for disposable consumer reconstruction.

```powershell
Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-794-04-022-keep-formatting-consistent-through-hydration'
& {
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  $node = 'C:\Program Files\nodejs\node.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release -p:Version=0.0.0-pin794
  & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
  $inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $call = { param($tool, $argument)
    & $node $inspector --cli --format json --quiet --method tools/call --tool-name $tool --tool-arg 'targetVersion="11.0"' --tool-arg $argument -- $dotnet $server mcp | ConvertFrom-Json
  }
  $entry = (& $call list_recipes 'query=culture-harbour').result.structuredContent.recipes
  if ($entry.id -ne 'blazor.align-server-browser-culture') { throw 'Missing discovery' }
  $entry | Format-List id, title, goal
  $recipe = (& $call get_recipe 'id=blazor.align-server-browser-culture').result.structuredContent.recipe
  if ($recipe.edition -ne '11.0' -or -not $recipe.markdown -or $recipe.markdown.Contains('{{snippet:')) { throw 'Incomplete recipe' }
  $recipe | ConvertTo-Json -Depth 30 | Set-Content ./artifacts/pin794-recipe.json
  $recipe | Format-List id, edition, stability
  $recipe.markdown
  $recipe.applicability.routes | ConvertTo-Json -Depth 30
  $recipe.sources | Format-Table title, url -Wrap
  $recipe.evidence | Format-Table sample, target, sdk, language, kind, freshness
}
```
