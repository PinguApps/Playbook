## Tested Inspector handoff

The exact block below passed from unrelated C:\Windows. It builds the server, lists real tools, and prints discovery ID/title/goal, complete expanded Markdown, every applicability property, edition, stability, official sources and current evidence. Expected discovery: `blazor.preload-needed-resources`, “Load needed resources during enhanced navigation”, edition 11.0. The complete details explain “Blazor enhanced navigation; only resources actually needed”, stable APIs executed on RC2, and both actual compile records. This block retrieves guidance; the separate receipts above establish browser behavior.

```powershell
Set-Location -LiteralPath 'V:\_worktrees\Playbook\agent-pin-800-04-028-retain-deliberate-loading-hints-during-enhanced'
$ErrorActionPreference = 'Stop'
$PSNativeCommandUseErrorActionPreference = $true
$env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
$env:DOTNET_GENERATE_ASPNET_CERTIFICATE = 'false'
$env:DOTNET_SKIP_FIRST_TIME_EXPERIENCE = '1'
$dotnet = 'C:\Program Files\dotnet\dotnet.exe'
$node = 'C:\Program Files\nodejs\node.exe'
New-Item -ItemType Directory -Path ./artifacts/PIN-800/inspect -Force | Out-Null
& $dotnet build ./src/PinguApps.Playbook -c Release -p:Version=0.0.0-pin800.4 -p:EnableSourceLink=false -p:IncludeSourceRevisionInInformationalVersion=false -p:EnableSourceControlManagerQueries=false
$inspectorPath = './artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js'
if (-not (Test-Path -LiteralPath $inspectorPath)) {
  & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
}
$inspector = (Resolve-Path -LiteralPath $inspectorPath).Path
$server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
$tools = & $node $inspector --cli --format json --quiet --method tools/list -- $dotnet $server mcp | ConvertFrom-Json
$tools.result.tools | Format-List name, description
$call = { param($tool, $argument)
  & $node $inspector --cli --format json --quiet --method tools/call --tool-name $tool --tool-arg 'targetVersion="11.0"' --tool-arg $argument -- $dotnet $server mcp | ConvertFrom-Json
}
$entry = (& $call list_recipes 'query=tern-ledger').result.structuredContent.recipes
if ($entry.id -ne 'blazor.preload-needed-resources') { throw 'Missing discovery' }
$entry | Format-List id, title, goal
$recipe = (& $call get_recipe 'id=blazor.preload-needed-resources').result.structuredContent.recipe
if ($recipe.edition -ne '11.0' -or -not $recipe.markdown -or $recipe.markdown.Contains('{{snippet:')) { throw 'Incomplete recipe' }
$recipe | Format-List id, edition, stability
$recipe.markdown
$recipe.applicability | ConvertTo-Json -Depth 40
$recipe.sources | Format-Table
$recipe.evidence | Select-Object sample, target, sdk, kind, freshness | Format-Table
[IO.File]::WriteAllText((Join-Path (Get-Location) 'artifacts/PIN-800/inspect/recipe.json'), ($recipe | ConvertTo-Json -Depth 60).Replace("`r`n", "`n") + "`n")
```
