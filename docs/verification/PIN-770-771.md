## Inspect what an agent receives

Requires PowerShell 7, SDK 10.0.402 and Node 22.19+ (tested Node 24.21.0 / Inspector 2.11.0). The first npm command downloads Inspector into ignored artifacts with lifecycle scripts disabled. It does not install a global command or change PATH. No SDK 11 is needed to read the embedded guidance. Tested starting from the unrelated temporary directory; the literal `Set-Location` selects this checkout before relative paths.

```powershell
Set-Location -LiteralPath 'C:\Users\pingu\.t3\scratch\2026-10-22-implement-task-linear-pin-770-0c2706c0'
$ErrorActionPreference = 'Stop'
$PSNativeCommandUseErrorActionPreference = $true
$env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
$dotnet = 'C:\Program Files\dotnet\dotnet.exe'
$node = 'C:\Program Files\nodejs\node.exe'
& $dotnet build ./src/PinguApps.Playbook -c Release
& 'C:\Program Files\nodejs\npm.cmd' install --prefix ./artifacts/inspector-2.11.0 --ignore-scripts --no-audit --no-fund --package-lock=false @modelcontextprotocol/inspector@2.11.0
$server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
$inspector = (Resolve-Path ./artifacts/inspector-2.11.0/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
$cli = @('--cli', '--format', 'json', '--quiet')
& $node $inspector @cli --method tools/list -- $dotnet $server mcp
$list = & $node $inspector @cli --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="11.0"' --tool-arg 'query=nuget-artifacts-hosts' -- $dotnet $server mcp | ConvertFrom-Json
$list.result.structuredContent.recipes | Format-List id, title, goal
foreach ($id in $list.result.structuredContent.recipes.id) {
    $result = & $node $inspector @cli --method tools/call --tool-name get_recipe --tool-arg "id=$id" --tool-arg 'targetVersion="11.0"' -- $dotnet $server mcp | ConvertFrom-Json
    $result.result.structuredContent.recipe.markdown
    $result.result.structuredContent.recipe.applicability | ConvertTo-Json -Depth 20
}
```

Expect exactly the two NuGet artifact/host goals, full older/newer guidance and target-11 applicability. Timestamps require fixed opt-in. Client hosts require actual NuGet.Packaging 8.0.0-rc.605 net10.0 assets. Requesting the client-host ID with `targetVersion="10.0"` returns the conditional .NET 10 route; requesting timestamps for target 10 fails with `no_applicable_edition`. Every connection starts and closes the actual stdio server. The Inspector check uses the built server; installed offline proof is separately provided by the package harness.
