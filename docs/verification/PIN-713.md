## Inspect what an agent receives

Requires PowerShell 7.3+, SDK 10.0.402 and Node 22.19+. This follows [the MCP Inspector walkthrough](../inspect-guidance.md) using the tested direct Node entry point. Setup downloads Inspector dependencies into ignored artifacts; Playbook itself serves embedded guidance without network retrieval. No .NET 11 SDK is needed merely to read it.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $PSNativeCommandUseErrorActionPreference = $true
    Set-Location -LiteralPath (git rev-parse --show-toplevel)
    dotnet build ./src/PinguApps.Playbook -c Release
    npm install --prefix ./artifacts/inspector-2.11.0 --no-audit --no-fund --package-lock=false @modelcontextprotocol/inspector@2.11.0
    $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
    $inspector = (Resolve-Path ./artifacts/inspector-2.11.0/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
    $cli = @('--cli', '--format', 'json', '--quiet')
    node $inspector @cli --method tools/list -- dotnet $server mcp
    $catalogue = node $inspector @cli --method tools/call --tool-name list_recipes --tool-arg 'targetVersion="11.0"' --tool-arg 'query=enclosing loop' -- dotnet $server mcp | ConvertFrom-Json
    $catalogue.result.structuredContent.recipes | Format-List id, title, goal
    $response = node $inspector @cli --method tools/call --tool-name get_recipe --tool-arg id=csharp.control-nested-loops --tool-arg 'targetVersion="11.0"' -- dotnet $server mcp | ConvertFrom-Json
    $recipe = $response.result.structuredContent.recipe
    $recipe | Format-List id, edition, introducedIn, title, goal
    $recipe.markdown | Show-Markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 15
}
```

Expect exactly list_recipes/get_recipe, one matching discovery entry titled **Stop or continue an enclosing loop directly**, and its explanatory goal about nested traversal and cleanup. Detail must contain the full older/newer declarations and expected trace, edition/introduction **11.0**, one **11.0** primary route, SDK family **11.0**, C# **15.0** and the RC2 limitation. Unresolved snippet tokens, a missing body or missing applicability are failures. Inspector shuts down each server automatically.
