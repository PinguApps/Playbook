## Inspect what an agent receives

Adapted from [the MCP Inspector walkthrough](../inspect-guidance.md).
PowerShell 7, .NET SDK 10.0.402 and Node 22.19+ are required. Setup uses network
access; the built server serves embedded guidance offline. No global installer,
lifecycle script, PATH change or account is needed.

```powershell
& {
  Set-Location -LiteralPath 'V:\_worktrees\Playbook\t3-7563cf95'
  $ErrorActionPreference = 'Stop'
  $PSNativeCommandUseErrorActionPreference = $true
  $env:DOTNET_ADD_GLOBAL_TOOLS_TO_PATH = '0'
  $dotnet = 'C:\Program Files\dotnet\dotnet.exe'
  $node = 'C:\Program Files\nodejs\node.exe'
  & $dotnet build ./src/PinguApps.Playbook -c Release
  & $node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install --prefix ./artifacts/inspector --ignore-scripts --no-audit --no-fund @modelcontextprotocol/inspector@2.11.0
  $inspector = (Resolve-Path ./artifacts/inspector/node_modules/@modelcontextprotocol/inspector/clients/launcher/build/index.js).Path
  $server = (Resolve-Path ./src/PinguApps.Playbook/bin/Release/net10.0/PinguApps.Playbook.dll).Path
  $call = { param($tool, $argument)
    & $node $inspector --cli --format json --quiet --method tools/call --tool-name $tool --tool-arg 'targetVersion="11.0"' --tool-arg $argument -- $dotnet $server mcp | ConvertFrom-Json
  }
  $list = & $call list_recipes 'query=validation-observability'
  $list.result.structuredContent.recipes | Format-List id, title, goal
  foreach ($entry in $list.result.structuredContent.recipes) {
    $detail = & $call get_recipe "id=$($entry.id)"
    $recipe = $detail.result.structuredContent.recipe
    $recipe | Format-List id, edition, introducedIn
    $recipe.markdown
    $recipe.applicability.routes | ConvertTo-Json -Depth 15
  }
}
```

Expect five ID/title/goal summaries, full original older/newer comparisons,
edition/introduction 11.0 and explicit runtime/SDK/language/framework/package/
provider/platform/rendering/stability conditions. An unresolved snippet, missing
body/applicability or unsupported .NET 10 edition is a failure. Every Inspector
call starts and closes the real built stdio server. The exact block is replayed
from C:\Windows before handoff. The installed package scenario independently
checks all rendered bodies/snippets, representations, discovery goals, editions,
fresh evidence and .NET 10 rejection through the existing isolated feed/cache
harness; it does not substitute the built server for artifact verification.
