# Target GA guidance using RC evidence

Playbook's .NET 11 guidance targets the full release. Pingu chose to prepare it now from current release-candidate evidence, then reconcile final release notes and API behavior at GA and publish corrections or additions. This avoids maintaining a catalogue of temporary preview approaches. Actual verification records must still identify the RC or GA artifacts used; preparing GA-targeted guidance does not establish GA verification. Treatment of APIs deliberately experimental after GA remains a separate scope decision.
